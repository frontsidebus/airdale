**voice.py — Refactor VoiceOutput (per D-04, D-12, pattern 5 from RESEARCH):**

1. Add import at top: `from .tts import TTSClient`

2. Change VoiceOutput constructor to accept TTSClient instead of raw credentials:
   ```python
   def __init__(
       self,
       tts_client: TTSClient,
       sample_rate: int = 24000,
   ) -> None:
       self._tts = tts_client
       self._sample_rate = sample_rate
       self._cancelled = False
       self._playing = False
   ```
   Remove `self._api_key`, `self._voice_id`, `self._model_id` — no longer needed.

3. Replace `_synthesize()` method. The current method (lines 321-349) creates an inline httpx.AsyncClient, calls ElevenLabs directly with hardcoded voice settings `{stability: 0.5, similarity_boost: 0.75, style: 0.3}`. Replace with:
   ```python
   async def _synthesize(self, text: str) -> bytes | None:
       try:
           return await self._tts.synthesize(text)
       except Exception as e:
           logger.warning("TTS synthesis failed: %s", e)
           return None
   ```
   This removes the inline httpx call and the hardcoded voice settings (D-04). Settings now come from config via the TTSClient.

4. Update `speak()` method: Remove the early-return check for `self._api_key or self._voice_id` at line 270. The TTSClient already encapsulates whether TTS is configured. 5. Update `speak_streamed()` method: Same as step 4 — remove the `self._api_key or self._voice_id` guard at line 287.

6. Remove the `import httpx` from voice.py since it's no longer used directly for TTS (check if httpx is used anywhere else in the file first — if only for TTS, remove it).

   ```python
           sanitized = preprocess_for_tts(phrase)
           if not sanitized or sanitized in _TTS_CACHE:
               continue
           try:
               _TTS_CACHE[sanitized] = await tts.synthesize(sanitized)
           except Exception as exc:
               logger.debug("Failed to cache TTS phrase '%s': %s", sanitized, exc)
   ```
   Call this during startup with the TTSClient instance. Per D-08, the cache stays in the web server.
