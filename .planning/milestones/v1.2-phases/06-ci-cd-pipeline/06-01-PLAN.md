  <action>
Create `.github/workflows/python-ci.yml` with the following structure per D-01, D-02, D-03, D-06, D-07, D-08:

**Triggers (per D-02, D-03):**
- `push` to `main` branch with paths: `orchestrator/**`, `telemetry-service/**`, `web/**`, `*.py`, `.github/workflows/python-ci.yml` (include workflow itself per Pitfall 6 from research)
- `pull_request` with same paths

**Job 1: `lint-and-test` (per D-06):**
- runs-on: `ubuntu-latest`
- Steps:
  1. `actions/checkout@v4`
  2. `actions/setup-python@v5` with `python-version: '3.12'` and `cache: 'pip'` (per research recommendation for built-in pip caching). Set `cache-dependency-path` to `orchestrator/pyproject.toml\ntelemetry-service/pyproject.toml\nweb/requirements.txt` so cache key covers all three.
  3. Install orchestrator dev deps: `cd orchestrator && pip install -e ".[dev]"` (this gets pytest, pytest-asyncio, ruff per CICD-01)
  4. Install telemetry-service dev deps: `cd telemetry-service && pip install -e ".[dev]"`
  5. Install web deps: `pip install -r web/requirements.txt` then `cd web && pip install -e ".[dev]"` (gets httpx-ws, pytest, pytest-asyncio)
  6. Ruff lint (per CICD-01): `ruff check orchestrator/ telemetry-service/ web/ --config orchestrator/pyproject.toml`
  7. Ruff format check: `ruff format --check orchestrator/ telemetry-service/ web/ --config orchestrator/pyproject.toml`
  8. Orchestrator tests (per CICD-02): `cd orchestrator && pytest`
  9. Telemetry service tests (per CICD-03): `cd telemetry-service && pytest`
  10. Web server tests (per CICD-07): `pytest web/tests/`

**Job 2: `integration` (per D-07, D-08):**
- `if: github.event_name == 'pull_request'`
- `needs: lint-and-test` (only run if lint+test passes)
- runs-on: `ubuntu-latest`
- Steps:
  1. `actions/checkout@v4`
  2. `actions/setup-python@v5` with `python-version: '3.12'` and `cache: 'pip'`
  3. Install orchestrator dev deps: `cd orchestrator && pip install -e ".[dev]"`
  4. Start services: `docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d whisper chromadb` (dev overlay gives tiny model per D-08)
  5. Wait for Whisper health: `timeout 120 bash -c 'until curl -sf http://localhost:9090/health; do sleep 5; done'` (port 9090 per compose mapping, per Pitfall 3)
  6. Wait for ChromaDB health: `timeout 30 bash -c 'until curl -sf http://localhost:8000/api/v1/heartbeat; do sleep 2; done'`
  7. Run integration tests: `cd orchestrator && pytest -m integration`
  8. Stop services (with `if: always()`): `docker compose down`

Use YAML block scalars (`|`) for multi-line run steps. Add concise `name:` labels to every step.
