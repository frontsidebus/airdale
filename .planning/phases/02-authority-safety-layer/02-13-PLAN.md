<objective>
Deliver the half of AUTH-06 that was built and then orphaned, on the CLI path.

Purpose: `OverrideDetector` constructs a `ProactiveEvent` saying "You've taken the flaps. I'm
advisory only until you're done." and another saying "Back to full authority whenever you want
me." Both go into an unbounded `asyncio.PriorityQueue` that nothing in this repository reads.
Three separate executors (02-08, 02-09, 02-10) independently noticed and each declined to mark
AUTH-06 complete for it. The requirement says a detected override "drops authority to
`advisory` for a cooldown period **and informs the pilot**"; the drop works, the informing does
not exist on any path.

The CLI is worse off than the browser: the browser at least moves a badge on the next status
poll, while `main.py`'s `/status` and `/health` never call `AuthorityState.summary()` at all, so
a CLI operator cannot tell whether MERLIN is refusing commands because of `AUTHORITY_LEVEL`, an
override cooldown, a latched watchdog or a degraded subsystem — the precise ambiguity D-10
exists to remove (WR-07).

Output: a bounded, never-raising publish path in the detector; a background drain task on the
CLI that prints each announcement and speaks it through `VoiceOutput`; authority in `/status`
plus a dedicated `/authority` command; and tests that exercise all three without constructing
an `Orchestrator`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| telemetry callback -> announcement queue | Runs inside `TelemetryClient`'s subscriber loop, which swallows subscriber exceptions; anything that can raise here fails silently |
| announcement queue -> pilot | The delivery path for AUTH-06. A dropped or undelivered announcement means MERLIN silently stopped acting on the aircraft |
| `AuthorityState` -> CLI stdout | The operator's only unmediated view of what MERLIN may currently do |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-13-01 | Repudiation | An override drop that the pilot is never told about | mitigate | `drain_authority_events` prints and speaks every event; tested for both callbacks and for priority order. Severity high — this is the requirement AUTH-06 exists to state |
| T-02-13-02 | Denial of Service | Unbounded queue growth with no consumer | mitigate | `maxsize=MAX_PENDING_ANNOUNCEMENTS` (32) plus a non-raising `_publish` with a logged discard. Severity low as a leak, medium as a signal — a full queue is now the visible symptom of a missing consumer rather than an invisible one |
