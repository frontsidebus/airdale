<objective>
Put the authority policy decision at the single point where a command is fully resolved,
safety-checked, and not yet transmitted, and stop `carb_heat` / `fuel_pump` from doing the
opposite of what was asked.

Purpose: AUTH-01 through AUTH-04 plus CMD-08. D-03 makes this location mandatory rather
than convenient — `assisted` is defined as "execute if safety is clean, withhold on
`warning`", so the gate must sit where the `SafetyResult` exists. `tools.py:239-271` already
resolves the command, fetches `SimState`, runs `command_safety`, and short-circuits on
`blocked`; the gate slots in between that short-circuit and `send_command`.

Output: an `authority` keyword parameter on `set_aircraft_control` and
`undo_last_command`, the three-level gate, the CMD-08 refusal, a parametrised
level-by-severity test matrix, and the `docs/SMART_CONTROLS.md` authority reference.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04-01 | Elevation of Privilege | Authority bypass via a caller that omits `authority=` | mitigate | Three layers, not one. (1) Both composition roots guarantee a non-`None` `AuthorityState`: `main.py` lets a construction failure propagate and abort startup (plan 02-08), and the web `lifespan` substitutes `AuthorityState.degraded_fallback(...)` (plan 02-09) — so in a wired process `None` is unreachable. Severity high — this exact "remember to add the check" failure already happened once with `command_safety` and `procedures.py` |
| T-02-04-02 | Elevation of Privilege | Prompt-based enforcement | mitigate | The gate is a code branch; no authority text is added to `TOOL_DEFINITIONS` or the system prompt (D-08). Severity high — a prompt-level guard is defeated by any prompt injection reaching the conversation |
| T-02-04-03 | Tampering | `blocked` being masked by an authority branch | mitigate | The `blocked` short-circuit runs before the gate and is not moved or duplicated; three of the nine matrix cases assert `blocked` still wins. Severity high |
