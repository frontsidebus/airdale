<objective>
Put a structural floor and the watchdog counter at the last point before a command leaves
the process, and give override detection a single-clock provenance channel.

Purpose: D-05 and AUTH-07. The floor exists because the "remember to add the check"
approach has already failed once in this exact code path — `command_safety` was wired into
`tools.py` and never into `procedures.py`, and nothing detected it for months. The watchdog
counter lives here because RESEARCH B3 proved it cannot live anywhere else: the tool layer's
own `asyncio.wait_for(5.0)` starts first and pre-empts `send_command`'s identical deadline,
so `{"success": False, "error": "Command timed out"}` is never reliably produced for a
caller to observe.

Output: an injected `AuthorityState` and `HealthMonitor` on `TelemetryClient`, a level-only
refusal in `send_command`, a consecutive-timeout counter with a reconnect clear, a
`command_path` health subsystem, and a bounded dispatch ledger for plan 02-06.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| in-process caller → `TelemetryClient.send_command` | The last in-process boundary; anything past this point is on the wire to the telemetry service and the adapter |
| adapter → `command_ack` frame | An ack, or its absence, is the only evidence the orchestrator has about whether the command path is alive |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05-01 | Elevation of Privilege | A second write path reaching the sim without passing the gate | mitigate | Level-only floor in `send_command` refuses at advisory regardless of caller (D-05). The floor is only inert if the client itself was built without an authority state, which both composition roots now prevent — `main.py` aborts startup on a construction failure (plan 02-08) and the web `lifespan` substitutes `AuthorityState.degraded_fallback(...)` (plan 02-09) — and a client built without one logs a WARNING at construction. Severity high — `procedures.py` is a live instance of exactly this failure today, and the floor is what makes a future third caller safe by construction |
| T-02-05-02 | Spoofing | Watchdog fed by tool-layer cancellations instead of real ack timeouts | mitigate | The counter is incremented inside `send_command` at the ack future, never inferred from a tool return dict (RESEARCH B3). Severity high — a counter fed by the wrong signal either never latches or latches on healthy commands |
| T-02-05-03 | Denial of Service | Watchdog latch deadlocking command issuance permanently | mitigate | `clear_watchdog()` is called on both `CONNECTED` transitions (D-18); telemetry flow is out-of-band evidence on the same socket, so no probe traffic and no pilot action is needed. Severity high |
| T-02-05-04 | Denial of Service | Re-latch storm from floor-refused commands counting as timeouts | mitigate | The floor returns before any counter mutation, pinned by an explicit ordering test. Severity medium |
| T-02-05-05 | Denial of Service | Spurious latch from adapter `success: false` acks | mitigate | A received ack resets the counter regardless of its `success` field. Severity medium — 31 unregistered events currently produce this ack shape routinely |
| T-02-05-06 | Repudiation | Command-path failure invisible to the pilot | mitigate | `command_path` registered on `HealthMonitor` and updated on every outcome, so `/api/status` can render "advisory (command path down)" (D-17, surfaced in plan 02-09). Severity medium |
| T-02-05-07 | Information Disclosure | Dispatch ledger retaining command history unboundedly | mitigate | `collections.deque` with `maxlen = DISPATCH_LEDGER_SIZE` (64); it holds only event names and monotonic timestamps, no values or state snapshots. Severity low |
| T-02-05-08 | Elevation of Privilege | Time-of-check / time-of-use between the authority check in `tools.py` and the dispatch in `send_command` — a level that drops in the interval (watchdog latch, pilot override, degraded fallback) could be actioned against a stale verdict | mitigate | The floor re-reads `self._authority.level` at the point of dispatch; it takes no caller-supplied level, holds no cached copy, and an acceptance criterion asserts `send_command` has no `level` parameter. Both reads also execute in the same synchronous slice with no intervening `await`, so under asyncio's cooperative scheduling no other coroutine can mutate the state between them today — but the design does not rely on that, because the fresh re-read remains correct if an `await` is ever introduced between the gate and the dispatch. Severity medium — structurally closed rather than argued away, and explicitly named here because it was a named threat for this phase |
| T-02-05-SC | Tampering | pip installs | accept | This plan installs no packages; the circuit breaker is roughly 30 hand-written lines, deliberately not a dependency. RESEARCH.md §Package Legitimacy Audit records zero new dependencies |
