<objective>
Close the browser half of Gap 1, and make the turn-probe endpoint keep the promise its own
docstring makes.

Purpose: `web/server.py` grew explicit `advisory` and `withheld` arms in plan 02-09, and the
docstring above them says the three-way split exists precisely because
`success = "error" not in result` reported a command that was never transmitted as executed.
The heuristic then survived verbatim in the fall-through arm. `TelemetryClient.send_command`
returns a negative adapter ack as `{"success": False, "message": ...}` with no `error` key —
a shape `sim_client.py` documents as routine — so the browser paints a green tick on a command
the adapter refused. That is the same false confirmation the phase set out to delete, one
branch further down.

Second, `/api/turn-probe` documents "Never raises. Every failure path returns a not-ended
answer", and then calls `decode_webm_to_samples` outside any `try`. With no ffmpeg on `PATH`
that raises `FileNotFoundError` and the browser takes a 500 on every probe during speech.
Every existing probe test patches the decode call, so nothing sees it.

Output: a success computation that reads the result instead of guessing at it, a guarded
decode call, and tests for both — including the exact `{"success": False}`-with-no-`error`
case the suite has never had.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| orchestrator tool result -> browser frame | `_on_tool_result` translates an untrusted-shaped dict into a claim the pilot reads as fact |
| browser -> `/api/turn-probe` | Unauthenticated, CORS-open, spawns an ffmpeg subprocess per accepted call; the body is attacker-influenced binary |
| display -> pilot | A green tick is an assertion about the aircraft, not about the software |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-12-01 | Spoofing | Negative adapter ack rendered as an executed command | mitigate | `success = bool(result.get("success", False)) and "error" not in result`, pinned by a `_NACKED_RESULT` test case. Severity high — the pilot is told the gear moved when the adapter refused the command |
| T-02-12-02 | Spoofing | An unrecognised result shape defaulting to success | mitigate | `result.get("success", False)` defaults to `False`; a dedicated fail-closed test. Severity medium |

Severity medium — the symptom is a traceback per probe plus added latency before the browser reaches its fallback |

  extending `_on_tool_result`'s tool-name guard is one line, but the frame it would build is

- IN-05 (the probe throttle table is keyed by IP so two tabs share a slot) — cosmetic; the
