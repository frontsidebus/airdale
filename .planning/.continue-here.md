## Decisions that constrain future work

**Cascade stays; speech-to-speech would mean replacing Claude.** Every S2S and
speech-LLM option (Moshi, Qwen-Omni, Ultravox) needs an open-weight LLM backbone
to attach an audio adapter to. Claude is API-only. Separately, `validation.py`
scans Claude's *response text* for V-speeds, altitudes, and frequencies — an
audio-out model produces nothing to validate. Adopting S2S should require an ADR,
not an incremental slide. Full analysis: `.planning/TECH-STACK-REVIEW.md` §2–3.

**Gate STT swaps on aviation-term WER, not published WER.** Published WER is
dominated by conversational filler and cannot distinguish a backend that drops
"uh" from one that hears "one zero thousand" as "one thousand".

**Synthetic eval audio is for CI regression and SNR curves only.** Clean TTS makes
every backend score near-perfect, so the gate stops discriminating; synthetic
speech is also common ASR training augmentation, which can flatter cloud backends
over local ones.

## Gotchas that cost time this session

- **Run ruff exactly as CI does**, from the repo root:
  `ruff check orchestrator/ telemetry-service/ web/ --config orchestrator/pyproject.toml --extend-ignore SIM105,SIM117,F841,B008,B017,B007,UP041`.
  `ruff check .` from inside `orchestrator/` demands the *opposite* import
  grouping (isort's `src` resolves against cwd) and has broken CI.
- **`gh pr checks` saying "no checks reported"** usually means the PR is
  `CONFLICTING` — GitHub won't run checks on a conflicting merge. Check
  `gh pr view N --json mergeable` before assuming CI is slow.
- **`gsd-sdk query ... --raw` returns JSON**, not a bare string.
- **`gsd-sdk query state.update`** also rewrites adjacent frontmatter fields;
  check the diff after using it.
